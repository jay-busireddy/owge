This package implements the mechanism-adequacy experiment requested after the first two OWGE studies.

- `CONFIRMATORY_PROTOCOL.md` — frozen scientific protocol and hypotheses.
- `RUN_WINDOWS.md` — exact Windows/laptop commands.
- `requirements.txt` — non-PyTorch dependencies.

Recommended sequence:
1. Read `CONFIRMATORY_PROTOCOL.md`.
2. Follow `RUN_WINDOWS.md`.
3. Run the optional smoke test.
4. Run the single prespecified 40-seed confirmatory experiment.
5. Upload the complete result ZIP without changing parameters after looking at p-values.

Observer ladder:
O1 central-only -> O3 weighted observation -> O4R replay-only -> O4M associative memory -> O4D associative validated dream consolidation.
